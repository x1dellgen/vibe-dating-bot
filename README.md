# Dating Telegram Mini App
Система для знакомств внутри Telegram.

## Стек технологий
- **Backend:** FastAPI (Python)
- **Frontend:** React (Vite)
- **Database:** SQLite (в будущем планируется миграция на PostgreSQL)

## Запуск
1. **Backend:** `cd backend && uvicorn main:app --reload`
2. **Frontend:** `cd frontend && npm run dev`
